## 🚀 Proyectos destacados

### 📊 ContaCore

<p align="justify">
<strong>ContaCore</strong> es un sistema de gestión contable desarrollado para centralizar y automatizar procesos financieros y contables desde una sola plataforma.
</p>

<p align="justify">
El sistema permite administrar ingresos, gastos, clientes, proveedores, obligaciones, cuentas por cobrar, cuentas por pagar, plan de cuentas, asientos contables y diferentes reportes financieros.
</p>

Entre sus funcionalidades se encuentran:

- Gestión de ingresos.
- Gestión de gastos.
- Gestión de clientes.
- Gestión de proveedores.
- Cuentas por cobrar.
- Cuentas por pagar.
- Obligaciones y pagos.
- Plan de cuentas.
- Asientos contables.
- Libro Diario.
- Libro Mayor.
- Balanza de comprobación.
- Estado de resultados.
- Balance general.
- Dashboard financiero.
- Autenticación mediante JWT.
- Control de acceso mediante roles.

<p align="justify">
El sistema utiliza principios de <strong>partida doble</strong>, generando automáticamente los movimientos contables correspondientes cuando se contabilizan ingresos, gastos y otras operaciones.
</p>

<p align="justify">
Actualmente también estoy desarrollando su <strong>interfaz web profesional</strong>, incorporando módulos visuales para Dashboard, Ingresos, Gastos y las diferentes áreas administrativas y contables.
</p>

**Backend**

`Java 21` • `Spring Boot` • `Spring Security` • `JWT` • `Spring Data JPA` • `Flyway` • `Maven`

**Frontend**

`React` • `TypeScript` • `Vite` • `Tailwind CSS` • `Axios`

**Base de datos**

`PostgreSQL`
